job_applications

A candidate's application to one job posting. Written before the migration (2026_10_24_090000_create_job_applications_table) as part of HIRE-6 (.ai/specs/spec-HIRE-6-job-applications/).

Model: App\Models\JobApplication (HasUuids, HasFactory).

Personal data

cover_letter and the joined candidate name, email and headline are personal data. They are returned only to the applicant (/me/applications) and to the owning employer (/employer/applications), never from a public endpoint. Deleting a user deletes their applications (cascade).
